## 二分查找

所谓二分查找(也称之为折半查找)，即对于每一次二分查找都将区间分成更小的两个部分，通过二分查找的单调性，进而选择更小的区间查找。

二分查找的核心点：就是对于左右边界的移动，满足什么条件是需要移动左端点，满足什么条件是需要移动右端点。它和滑动窗口都需要遍历的元素集合需要满足一定的单调性，二分条件是什么。

通过对于区间开合的分类又可以分成三类：左开右开 $(l,r)$，左开右闭 $(l, r]$，左闭有闭 $[l,r]$。

>总结：二分查找这类问题就是要找到：区间端点如何移动，二分条件的判断，对什么信息进行二分查找。

### 左闭右闭区间的二分查找

在左闭右闭区间中，二分循环遍历的条件为 $l <= r$，左端点更新为 $l = mid + 1$，右端点更新为 $r = mid - 1$，最后返回的答案是 $l$，在二分查找的过程中，左端点左边的数(不包括左端点)全是已经确定的满足条件的值，右端点右边的数(不包括右端点)全是已经确定不满足条件的值(区间 $[l, r]$ 里面的数是不确定是否满足的值)。

```cpp
auto check = [&](int m) -> bool
{
    
};

int l = 0, r = n;
while(l <= r)
{
    int mid = l + (r - l) / 2; //防止溢出
    if(check(mid))
    {
        l = mid + 1;
    }
    else
    {
        r = mid - 1;
    }
}

return l; // r + 1也行
```

<details>
    <summary>
        代码实现
    </summary>
    给定一个升序数组，需要O(logn)查找一个目标值，升序满足二分查找单调性，于是可以使用二分查找解决<br>

```cpp
class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        if (nums.empty()) return {-1, -1};
        int left = 0, right = nums.size() - 1;
        int first = -1, last = -1;
        // 查找左边界
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] >= target) {
                right = mid - 1;
                if (nums[mid] == target) first = mid; // 更新左边界
            } else {
                left = mid + 1;
            }
        }
        // 查找右边界
        left = 0, right = nums.size() - 1; // 重置指针
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] <= target) {
                left = mid + 1;
                if (nums[mid] == target) last = mid; // 更新右边界
            } else {
                right = mid - 1;
            }
        }
        // 验证结果有效性
        if (first != -1 && last != -1 && first <= last) {
            return {first, last};
        }
        return {-1, -1};
    }
};
```

## 二分答案

所谓二分答案本质上是对二分查找的应用，将遍历集合元素的单调性转化为二分信息与条件约束之间的单调性，从而使用二分答案查询一个条件约束下的值。

难点在于二分 $check$ 函数的构建，以及二分上下界的找寻。

通过对查找值的分类有以下六种：求最小，求最大，二分间接值，最小化最大值，最大化最小值，第 $k$ 大/小。

### 求最小

对于这种题目，一般出题格式类似：“在不超过xx条件下，求最小xx”，那么我们可以得到左端点值越大，越能完成任务，越小越不能完成。

所以说约束和二分的信息成一个单调性，我们可以对其进行二分答案。最后如果使用的是左开右开区间，那么 右端点 $r$ 就是所求最小答案。

左右端点的移动式子为 $(check(mid)\ ?\ r : l) = mid$，如果当前答案满足约束，那么继续缩小边界，找最小的满足值。

### 例题

<details>
  <summary>
    <a href="https://leetcode.cn/problems/find-the-smallest-divisor-given-a-threshold/description/">LeetCode: 1283. 使结果不超过阈值的最小除数</a>
  </summary>

  给你一个整数数组 `nums` 和一个正整数 `threshold`，你需要选择一个正整数作为除数，然后将数组里每个数都除以它，并对除法结果求和。

  请你找出能够使上述结果小于等于阈值 `threshold` 的除数中**最小**的那个。

  **注意**：每个数除以除数后都向上取整，比方说 `7/3 = 3`，`10/2 = 5`。
  题目保证一定有解。

**示例 1**

  输入：`nums = [1,2,5,9], threshold = 6`
  输出：`5`
  解释：

  - 除数为 1 时，和为 `1+2+5+9 = 17`（超过阈值）；
  - 除数为 4 时，和为 `1+1+2+3 = 7`（超过阈值）；
  - 除数为 5 时，和为 `1+1+1+2 = 5`（≤6，符合要求）。    

**示例 2**

  输入：`nums = [2,3,5,7,11], threshold = 11`
  输出：`3`

**示例 3**
  输入：`nums = [19], threshold = 5`
  输出：`4`

**提示**
  - `1 <= nums.length <= 5 * 10^4`
  - `1 <= nums[i] <= 10^6`
  - `nums.length <= threshold <= 10^6`
</details>


<details>
    <summary>
        代码实现
    </summary>
    题目中说要找到一个最小的<b>x</b>，并且数组中所有的数除以<b>x</b>之后的和不超过一个上限。
    分析可得，<b>x</b>越大，越能满足约束条件，<b>x</b>越小，约不满足约束条件。
   <b>x</b>与约束条件呈现一个单调性，因此我们可以使用二分答案，二分<b>x</b>。


```cpp
class Solution
{
public:
    int smallestDivisor(vector<int> &nums, int threshold)
    {
        auto check = [&](int m) -> bool
        {
            int res = 0;
            for (int x : nums)
            {
                res += (x + m - 1) / m;
                if(res > threshold)
                {
                    return false;
                }
            }

            return true;
        };

        int l = 0, r = *max_element(nums.begin(), nums.end());

        while (l + 1 < r)
        {
            int mid = l + (r - l) / 2;
            (check(mid) ? r : l) = mid;
        }

        return r;
    }
};
```

### 求最大

对于这种题目，一般出题格式类似：“在不超过xx条件下，求最大xx”，那么我们可以得到左端点值越小，越能完成任务，越大越不能完成。

所以说约束和二分的信息成一个单调性，我们可以对其进行二分答案。最后如果使用的是左开右开区间，那么 左端点 $l$ 就是所求最大答案。

左右端点的移动式子为 $(check(mid)\ ?\ l : r) = mid$，如果当前答案满足约束，那么继续放大边界，找最大的满足值。

    	代码实现

```cpp
class Solution
{
public:
    int hIndex(vector<int> &citations)
    {
        auto check = [&](int m) -> bool {
            int res = 0;
            for(int x : citations)
            {
                res += x >= m ? 1 : 0;

                if(res >= m)
                {
                    return true;
                }
            }

            return false;
        };

        int l = -1, r = citations.size() + 1;
        while(l + 1 < r)
        {
            int mid = l + (r - l) / 2;
            (check(mid) ? l : r) = mid;
        }

        return l;
    }
};
```

### 二分间接值

有些时候要求的答案并不会直接和约束条件呈现单调性，但是有可能约束条件会和与答案有关的间接值呈现单调性(或者在二分过程中的间接值就是我们要求的答案)，我们可以通过二分答案间接值来满足约束条件，进而得到答案。

<details>
    <summary>
    	代码实现
    </summary>
    根据题目可以知道，正方形的边越长，所容纳的点越多，但是也更不满足约束条件，容易有标签相同的点，导致答案不合法。
    所以说由于边长<b>a</b>与约束条件成单调性，我们可以对正方形边长进行二分答案，然后在二分过程中不断更新最大的答案。

```cpp
class Solution
{
public:
    int maxPointsInsideSquare(vector<vector<int>> &points, string s)
    {
        int res = 0;
        auto check = [&](int m) -> bool
        {
            unordered_set<char> st;
            int cnt = 0;
            for (int i = 0; i < points.size(); i++)
            {
                int x = points[i][0], y = points[i][1];
                char tag = s[i];
                if (abs(x) <= m && abs(y) <= m)
                {
                    if (st.contains(tag))
                    {
                        return false;
                    }
                    else
                    {
                        st.insert(tag);
                        cnt++;
                    }
                }
            }

            res = max(cnt, res);
            return true;
        };

        int l = -1, r = 1e9 + 1;
        while (l + 1 < r)
        {
            int mid = l + (r - l) / 2;
            (check(mid / 2) ? l : r) = mid;
        }

        return res;
    }
};
```

### 最小化最大值

其实本质就是求最小值，但是字面描述不同，然后二分对象不同，二分对象变成了约束条件。

<details>
    <summary>
    	代码实现
    </summary>
    观察题目可得，要把数组分成<b>k</b>的小组的话，每一组所含有元素越多和越大，越少和越小，那么我们要求所有分组的和最大值最小，也就是说尽量使每个分组要小，那么可以知道所有分组的和的最大值越大，那么每组的所容纳的元素越多，那么就更可能完成<b>k</b>个分组，因此可得约束条件与所有和的最大值呈现单调性，那么我们可对约束条件进行二分答案，查看可能的答案是否能够使每组的和小于等于约束条件，并且可以分为<b>k</b>个分组。

```cpp
class Solution
{
public:
    int splitArray(vector<int> &nums, int k)
    {
        auto check = [&](int mx) -> bool
        {
            int res = 0;
            int cnt = 1;
            for (int x : nums)
            {
                if (res + x <= mx)
                {
                    res += x;
                    continue;
                }

                if (cnt == k)
                {
                    return false;
                }

                cnt++;
                res = x;
            }

            return true;
        };

        int l = *max_element(nums.begin(), nums.end()) - 1, r = accumulate(nums.begin(), nums.end(), 0);
        while (l + 1 < r)
        {
            int mid = l + (r - l) / 2;
            (check(mid) ? r : l) = mid;
        }

        return r;
    }
};
```

    	代码实现
    </summary>
    分析题目可得，我们需要选取<b>n</b>个整数，且对于每一个整数<b>i</b>都满足在区间<b>[start[i], start[i] + d]</b>里面，然后我们要求最大的得分，得分为所有数间隔的最小值，因此我们选取的整数间隔越小，越能满足题目区间要求，最小值的最大值会减小，选取的整数间隔越大，越不能满足区间要求，最小值的最大值会增大，
因此约束条件与最小值的最大值呈现单调性，我们可以对间隔二分答案，然后求出在当前间隔下，满足每个区间内选数的条件。

```cpp
class Solution
{
public:
    int maxPossibleScore(vector<int> &start, int d)
    {
        sort(start.begin(), start.end());
        auto check = [&](long long m) -> bool
        {
            long long res = LLONG_MIN;
            for (int x : start)
            {
                res = max(res + m, 1LL * x);
                if (res > x + d)
                {
                    return false;
                }
            }
            return true;
        };

        long long l = 0, r = (start.back() + d - start[0]) / (start.size() - 1) + 1;
        while (l + 1 < r)
        {
            long long mid = l + (r - l) / 2;
            (check(mid) ? l : r) = mid;
        }

        return l;
    }
};
```

### 第 $k$ 小/大

求第 $k$ 小、大的问题其实可以转化为下列两种情况，然后进行二分查找：

- 第 *k* 小等价于：求**最小**的 *x*，满足 ≤*x* 的数**至少**有 *k* 个。
- 第 *k* 大等价于：求**最大**的 *x*，满足 ≥*x* 的数**至少**有 *k* 个。

### 例题

<details>

    </summary>

乘法表是大小为 `m x n` 的一个整数矩阵，其中 `mat[i][j] == i * j`（下标从 **1** 开始）。

给你三个整数 `m`、`n` 和 `k`，请你在大小为 `m x n` 的乘法表中，找出并返回第 `k` 小的数字。

<details>
    <summary>
        代码实现
    </summary>
    分析题目可得，我们要找第<b>k</b>小的数字，可以转化为求最小的<b>x</b>，满足<b>≤ x</b>的数至少有<b>k</b>个。
    由于中乘法表使每一行每一列使天然有序单调递增的，满足单调性，因此我们可以使用二分答案来查找第<b>k</b>小的数字。
    由于每一行最后一个一定是这一行最大的，因此我们可以通过直接遍历所有行，然后比较当前<b>x</b>与该最后一个数的大小，如果小于，则说明这个数包含在这一行，从而快速求得大于当前<b>x</b>的个数。

```cpp    
class Solution
{
public:
    int findKthNumber(int m, int n, int k)
    {
        auto check = [&](long long x) -> bool
        {
            int cnt = 0;
            for (int i = 1; i <= m; ++i)
            {
                cnt += min(1LL * n, x / i);
                if (cnt >= k)
                {
                    return true;
                }
            }

            return false;
        };

        long long l = 0, r = n * m + 1;
        while (l + 1 < r)
        {
            long long mid = l + (r - l) / 2;
            (check(mid) ? r : l) = mid;
        }

        return r;
    }
};
```
